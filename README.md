# Rodent Identification

An AI and computer vision system for identifying, classifying, and monitoring rodent species from image and video captures.

## Features
- Species detection and visual classification
- Image and video inference pipelines
- Bounding box annotation and tracking
- Fast inference with local or cloud AI models

## Getting Started
1. Set up your environment and dependencies.
2. Place sample imagery or video feeds in the `data/` directory.
3. Run identification pipelines via `src/`.
